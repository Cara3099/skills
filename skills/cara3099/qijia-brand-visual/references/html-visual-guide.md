# 企加 HTML 视觉系统 0.3

这是当前定稿的 HTML 品牌视觉基准，适用于品牌手册、内部专题页、政策专题页和需要高质感展示的品牌化网页。

## 版式结构

- 顶部使用白色 Logo 区、深蓝品牌信息栏和横向分区导航；不要使用突兀的固定左侧菜单栏。
- 主体使用纸白底色与克制的小方格网格，形成资料、审计和财税场景的“工作纸”质感。
- 首页采用左侧大标题、下方三段价值说明和右侧深蓝线形品牌图；右侧品牌图保持原确认版设计，不改成抽象渐变或装饰卡片。
- 章节采用宽阔的编辑式信息区，序号、标题、说明和内容卡片按横向节奏排列；移动端自然收为单列。

## 视觉令牌

- 深蓝 `#172A4A`：品牌栏、标题、主结构。
- 正红 `#CE2A2A`：品牌信号、风险、重点标记和导航下划线。
- 纸白 `#F7F5EF`：页面底色。
- 墨色 `#15181D`：正文。
- 浅蓝灰 `#EDF2F8`：信息面板。
- 边框 `#D8DCE2`：卡片、表格和分隔线。

## 可读性底线

- Logo 必须完整、清晰、保持原比例，并放在白色或浅色干净区域。
- 页面各板块正文不使用过小字号；说明文字、卡片文字、表格文字和组件示例都应以现场阅读和普通显示器阅读为标准。
- 不用截图承载正文；所有文字保持 HTML 文本，便于放大、搜索、复制和打印。
- 桌面端必须检查 `scrollWidth` 不得超过 `clientWidth`；移动端检查标题、卡片和表格不发生遮挡或溢出。

## 复用方式

1. 复制 `assets/templates/html/qijia-brand-visual-system-0.3.html`。
2. 保留顶部品牌栏、横向导航、纸白网格和右侧深蓝品牌图结构。
3. 仅替换标题、说明、卡片、表格和示例内容；颜色、Logo 位置、边框和字号遵循本规范。
4. 完成桌面端、移动端和打印检查后再交付。
