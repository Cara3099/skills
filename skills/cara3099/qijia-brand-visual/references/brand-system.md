# 企加视觉系统 0.3

## 品牌定位

广东企加税务师事务所的文件视觉应体现：正式、合规、现代、清晰、可靠。页面的首要任务是帮助读者判断事实、风险和下一步行动，不做营销式装饰。

## 设计令牌

| 角色 | 色值 | 用途 |
|---|---|---|
| Navy | `#172A4A` | 标题、页眉、结构强调、封面品牌图 |
| Red | `#CE2A2A` | 风险、截止日期、少量品牌强调 |
| Ink | `#15181D` | 正文 |
| Paper | `#F7F5EF` | 纸张底色、封面底色 |
| Soft blue | `#EDF2F8` | 信息面板、表头、浅层分区 |
| Line | `#D8DCE2` | 边框、分隔线、表格线 |
| Muted | `#68717F` | 辅助信息、来源、页脚 |

## 标志规范

- 使用 `assets/brand/qijia-logo.png` 原始比例。
- Logo 应与“广东企加税务师事务所”组成横向锁定关系；公司名的视觉体量应不小于 Logo。
- 标志周围至少保留标志高度 0.35 倍的安全空间。
- 不压在深蓝或复杂纹理上；不描边、不加投影、不裁切。

## 排版规范

- 中文优先：苹方、思源黑体、微软雅黑；缺失时回退到常见无衬线字体。
- 8px 为基本间距单位，结构优先采用 16 栏网格或其简化形式。
- 卡片圆角不超过 8px，阴影尽量不用；以边框、留白和层级建立结构。
- 细小方格可用于封面、章节页和内容底板，透明度保持克制。
- 正文以左对齐为主；资料页、政策说明和长文采用自然阅读流，不硬拆两栏。

## 四种文件的共同层级

1. 品牌与文件身份。
2. 标题和日期。
3. 今日结论或执行摘要。
4. 事实、政策、影响、建议。
5. 行动清单。
6. 来源与正式提示。

## 质量底线

- 同一信息只出现一个权威版本。
- 数字、日期和文号在四种格式中一致。
- 读者一眼能分清“事实”“影响”“行动”“提示”。
- 正文打印后保持清晰；不以位图截图替代可编辑文字。
