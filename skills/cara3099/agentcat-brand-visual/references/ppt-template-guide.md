# 代理猫 PPT 模板使用指南

## 页面类型

1. 封面：标题、副标题、日期和项目类型。
2. 阶段快照：一个结论加少量状态信息。
3. 流程：按顺序呈现服务确认主链路。
4. 证据链：时间、事件、证据对象和状态。
5. 后续计划：分阶段列出三项以内重点工作。
6. 结论：一个主判断、一个行动建议和必要说明。

## 使用规则

- 从最接近内容的现有页面复制修改，不新增自由布局。
- 标题保持一至两行，不能出现孤字或单独标点；正文不小于 16pt。
- 只使用原始 Logo 与模板已有图形，不生成插画、背景图或其他装饰图片。
- 内容过多时拆页或删减，不缩小字号硬塞。
- 导出前逐页渲染并检查重叠、越界、字体替换、页脚和页码。
