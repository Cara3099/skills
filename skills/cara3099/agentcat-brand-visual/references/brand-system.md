# 代理猫品牌视觉系统参考

## 核心颜色令牌

| 用途 | 令牌 |
|---|---|
| 品牌主橙 | `#FF5001` |
| 深橙 | `#D94100` |
| 深墨蓝 | `#162033` |
| 辅助正文 | `#25324A` |
| 暖白 | `#FCFBF8` |
| 浅桃 | `#FFF0E8` |
| 极浅桃 | `#FFF8F4` |
| 暖灰边框 | `#E8E2DC` |
| 次级灰 | `#8A8F98` |

正文与背景尽量满足 WCAG AA 对比度。橙色用于短线、标题眉题、少量重点和主操作，不大面积铺满。

## 品牌口号

- 固定品牌口号：`代理记账认准代理猫`
- 可选副口号：`让合规创造价值`
- 禁止主动使用的旧项目文案：`让每一份服务确认，都清楚可查。`

该句不是品牌口号。模板和智能体不得主动使用；只有用户明确将其作为某个项目的临时标题时才可原样引用，且不得进入 Logo 锁定、固定页脚或品牌落款。

## 模型能力差异控制

- 优先使用 Skill 内模板、示例和脚本，不要求模型从空白页面推导视觉系统。
- PPT 直接继承模板页；Word 使用固定正文预设；Excel 继承工作簿；HTML 继承基准页面。
- 不生成品牌插画、吉祥物、背景图片、装饰图形或抽象纹理。
- 只使用 `assets/brand/agentcat-logo.png`。原图缺失时停止使用 Logo，不自行重绘或替代。

## Word 默认预设

- A4 单栏连续文字；正文黑色/深灰；不使用卡片、看板、拼贴和装饰性表格。
- 正文 10.5–11pt、1.5 倍行距；标题 16/14/12pt；通过标题、编号、加粗和间距突出重点。
- 页边距、页眉页脚、自动编号、与下段同页、段中不分页和签署页分页一次设置完成。
- 除真实重复字段或定量对照外，不使用表格承载普通段落。

## PPT 固定模板

- 英文路径：`assets/templates/ppt/agentcat-brand-visual-skill-template.pptx`
- 中文路径：`assets/templates/ppt/代理猫品牌视觉Skill完整模版.pptx`
- 预览：`assets/templates/ppt/agentcat-brand-visual-skill-preview.png`
- 模板包含封面、阶段快照、流程、证据链、后续计划和结论六类页面。

## 证据时间线

- 左侧放日期/版本，中间使用 1px 橙色规则线，右侧放事件与证据文字。
- 每个节点至少展示时间、事件、证据对象和文字状态，不依赖颜色单独传达含义。
- 历史确认不可覆盖；后续变化新增节点或补充确认。

## 内容边界

客户服务确认流程使用`服务单`或`服务确认单`。数据锚点为公司主体和税号。确认后保留确认快照；后续变化走补充确认，不覆盖原记录。
